# /frontend

React + Vite + TypeScript + Tailwind CSS. Renders the virtual keyboard UI, gaze cursor, key-probability visualisation, word/phrase suggestions, text display, and accessibility controls.

**Status:** not yet scaffolded. First real work happens in **Phase 2** (keyboard UI + gaze→key→text baseline) and expands in **Phase 6** (adaptive keyboard + Groq suggestions UI) and **Phase 11** (full product integration).

Consumes the WebSocket protocol described in `MASTER_PROJECT_DOCUMENT.md` Section 16 from the `/backend` server.
