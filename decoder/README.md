# /decoder

Key-probability mapping, the local character-level LM, and the joint noisy-channel decoder — the core research contribution (C1/C2).

- **Phase 2 (done):** `nearest_key.py` — hard nearest-key lookup against `config/keyboard_layout.json` (S0's degenerate, single-choice version of key-probability mapping). `dwell.py` — first, simple fixation/dwell detector (fixed threshold, no temporal aggregation yet). `text_buffer.py` — shared key-sequence → text buffer used by every S-system.
- **Phase 3 (done):** `key_probability.py` — integrates a diagonal 2D Gaussian `G ~ N(mu, Sigma)` over each key's rectangle (closed-form via erf, Section 8 Stage 2/3), producing a full normalized per-key probability distribution instead of S0's hard choice. `dwell.py`/`nearest_key.py` are unchanged and untouched — S0 still uses them as-is; the new Gaussian machinery is additive, consumed by `/vision`'s fixation aggregator (`vision/fixation.py`) and streamed by `/backend` as `key_probabilities`, ready for S1–S4 to actually decode against in Phase 5.
- **Phase 4 (done):** `char_lm.py` — local, deterministic character-level LM: order-4 interpolated n-gram over a-z + space (Section 13's local/reproducible requirement — deliberately not Groq-backed). `train_char_lm.py` trains it on NLTK's Gutenberg corpus (~10.5M chars) and saves to `/models/char_lm.json` (committed — small, deterministic, avoids everyone needing to retrain). Held-out perplexity 5.17; validated predictions are sensible (`"th"` → `"e"` at 62%, `"qu"` → vowels dominate). `next_char_probs(prefix)` and `log_prob(text)` are the two entry points Phase 5's decoder will use directly for the P(T) term.
- **Phase 5 (done):** `beam_search.py` — the shared noisy-channel search, `P(T|G) ∝ P(G|T)·P(T)`, used by both S1 (generic confusion likelihood) and S4 (real per-observation Gaussian likelihood). The S1-S4 systems themselves live in `/experiments` (`s1.py`-`s4.py`) since they're the runnable comparison scripts; this module is the piece they share.

This is the component the S1-vs-S4 experiment (H1) directly measures — keep it fully local and deterministic, no cloud LLM calls in this path.
